# Data Processor Agreement Template

## For GDPR (EU) and DPDPA (India) Compliance

**IMPORTANT:** This is a template. Customize for your specific vendors and have legal counsel review before signing.

---

## DATA PROCESSOR AGREEMENT

**Effective Date:** [DATE]

**Data Controller:** [YOUR HOSPITAL/ORGANIZATION NAME]

**Data Processor:** [VENDOR NAME, e.g., Amazon Web Services]

---

### 1. DEFINITIONS

**Data Controller:** [Your organization name], the entity that determines the purposes and means of processing personal data.

**Data Processor:** [Vendor name], the entity that processes personal data on behalf of the Data Controller.

**Personal Data:** Any information relating to an identified or identifiable natural person (patient).

**Processing:** Any operation performed on personal data (collection, storage, use, etc.).

---

### 2. SCOPE OF PROCESSING

The Data Processor agrees to process personal data only:
- As instructed by the Data Controller
- For the purposes specified in the service agreement
- In compliance with GDPR/DPDPA requirements

---

### 3. OBLIGATIONS OF DATA PROCESSOR

The Data Processor agrees to:

**a) Security Measures:**
- Implement appropriate technical and organizational measures
- Use encryption for personal data in transit and at rest
- Maintain secure access controls
- Regularly test and evaluate security measures

**b) Confidentiality:**
- Ensure persons authorized to process personal data are bound by confidentiality
- Not disclose personal data to third parties without Data Controller's consent
- Not use personal data for purposes other than those specified

**c) Data Breach Notification:**
- Notify Data Controller of any data breach within 72 hours (GDPR) or as required by law
- Provide details of the breach, including:
  - Nature of breach
  - Categories of data affected
  - Number of individuals affected
  - Likely consequences
  - Measures taken to address breach

**d) Data Subject Rights:**
- Assist Data Controller in responding to data subject requests:
  - Right to access
  - Right to rectification
  - Right to erasure
  - Right to data portability
  - Right to object

**e) Sub-processors:**
- Not engage sub-processors without Data Controller's prior written consent
- Ensure sub-processors are bound by same obligations
- Remain fully liable for sub-processor's compliance

**f) Data Localization (India/DPDPA):**
- Store personal data in India if required by DPDPA
- Not transfer personal data outside India without consent
- Comply with data localization requirements

---

### 4. OBLIGATIONS OF DATA CONTROLLER

The Data Controller agrees to:
- Provide clear instructions for processing
- Ensure processing is lawful
- Notify Data Processor of any changes in processing requirements
- Obtain necessary consents from data subjects

---

### 5. DATA RETENTION AND DELETION

**Retention:**
- Data Processor will retain personal data only as long as necessary
- Retention period: [SPECIFY, e.g., 6 years for healthcare records]

**Deletion:**
- Upon termination, Data Processor must delete or return all personal data
- Data Processor must certify deletion in writing
- If deletion is technically impossible, Data Processor must continue to protect data

---

### 6. AUDIT AND COMPLIANCE

Data Processor must:
- Maintain audit logs of personal data processing
- Allow Data Controller to audit processing activities
- Provide evidence of compliance upon request
- Cooperate with supervisory authorities

---

### 7. DATA TRANSFERS

**International Transfers (GDPR):**
- Data Processor may transfer personal data outside EU only if:
  - Adequate safeguards are in place (Standard Contractual Clauses, etc.)
  - Data Controller has given explicit consent
  - Transfer is necessary for performance of contract

**Cross-Border Transfers (DPDPA):**
- Data Processor may transfer personal data outside India only if:
  - Data Controller has given explicit consent
  - Transfer is necessary for performance of contract
  - Adequate safeguards are in place

---

### 8. LIABILITY AND INDEMNIFICATION

Data Processor agrees to:
- Be liable for damages caused by non-compliance
- Indemnify Data Controller for:
  - Regulatory fines and penalties
  - Costs of breach notification
  - Costs of data subject compensation

---

### 9. TERM AND TERMINATION

**Term:** This Agreement remains in effect until terminated.

**Termination:**
- Either party may terminate for material breach
- Upon termination, Data Processor must return or delete all personal data
- Data Processor must certify return/deletion in writing

---

### 10. GOVERNING LAW

**For GDPR (EU):**
- This Agreement is governed by [EU Member State] law
- Disputes will be resolved in [EU Member State] courts

**For DPDPA (India):**
- This Agreement is governed by Indian law
- Disputes will be resolved in Indian courts
